# 🌱 Smart Farming Assistant

An AI-powered web platform designed to support farmers with intelligent, data-driven insights for precision agriculture.

## 📌 Overview

**Smart Farming Assistant** is an integrated agricultural platform that helps farmers make better decisions using Artificial Intelligence, weather information, crop-related insights, and smart recommendations.

The platform aims to simplify farming decisions by providing useful information through an easy-to-use web interface.

## ✨ Features

* 🌦️ **Weather Information** — Provides weather-related information to support farming decisions.
* 🤖 **AI Farming Assistant** — Helps users with agriculture-related queries and recommendations.
* 🌾 **Crop & Farming Insights** — Provides useful information for better crop management.
* 📊 **Smart Recommendations** — Supports data-driven agricultural decision-making.
* 🎙️ **Voice Support** — Enables interaction through voice-based features.
* 🧠 **Machine Learning Models** — Uses ML models for intelligent predictions and analysis.
* 💻 **User-Friendly Web Interface** — Provides a simple and accessible platform for farmers.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Sanjeevini1403/Smart-Farming-Assistant-An-AI-Powered-Web-Platform-for-Precision-Agriculture.git
```

### 2. Navigate to the Project

```bash
cd Smart-Farming-Assistant
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

If a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

### 5. Configure Environment Variables

Create a `.env` file and add the required API keys.

```env
OPENWEATHER_API_KEY=your_api_key
GEMINI_API_KEY=your_api_key
```

> **Note:** Never commit your `.env` file or expose API keys publicly.

## ▶️ Running the Project

Run the backend and frontend according to the project configuration.

Refer to the respective folders for application-specific instructions.
